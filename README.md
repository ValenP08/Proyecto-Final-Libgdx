# Proyecto de juego similar a Zelda.

## Integrantes:
-Valentino Porro
-Nicolas Caravetta
-Gonzalo Degange

## Descripción:
Juego de combate y exploración 2D, basado en los juegos de Zelda clásicos, en el cual se podrá eliminar enemigos, jefes y encontrar secretos, mientras se avanza en las distintas regiones que posee el juego.

## Herramientas utilizadas: 
Java (Con eclipse), LibGDX, Piskel y Tiled Map Editor. La plataforma será PC.

## Cómo ejecutarlo: 
- Se debe descargar el juego y se extrae. 
- Posteriormente se importa en una aplicación que puede ser eclipse o intellij. 
- Se busca la dirección:"lwjgl3\src\main\java\com\Juego\zelda\lwjgl3". 
- Se hace click en el archivo "Lwjgl3Launcher.java" y se da a ejecutar adentro de la aplicación.
